# Course Tracker

A full-stack web application to manage courses (add, view, and delete) built with **Spring Boot**, **MySQL**, and **React (Vite)**.

## Tech Stack
- **Backend:** Java, Spring Boot, Spring Data JPA (Hibernate), Maven
- **Database:** MySQL
- **Frontend:** React, Vite
